# Icon credits

These SVG icons are bundled locally; no CDN or external font is used.
The derived paths in `virus-icons.js` preserve the original artwork. Paint is
normalized to currentColor and dimensions are responsive. Game-icons' solid
background squares are removed. Lucide stroke width is adjusted from 2 to 1.8.
